# Microsoft Store listing

One folder per Partner Center locale. `en-us` is the source. These texts replace the 2022 listing (MIT license text, x86 notes, and empty translations).

| File | Store field |
|---|---|
| `title.txt` | Product name. Keep this English name in every listing. |
| `short_title.txt` | Short title, sort title, and voice title |
| `short_description.txt` | Short description, one line, at most 256 characters |
| `description.txt` | Description |
| `features.txt` | Feature1–Feature9, one line each, at most 200 characters |
| `keywords.txt` | SearchTerm1–SearchTerm7, one line each, at most 40 characters, 21 words in total |
| `release_notes.txt` | Release notes, at most 1500 characters |
| `screenshot_captions.txt` | Captions for the Recording, Settings, and About screenshots, one each |
