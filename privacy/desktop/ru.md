# Политика конфиденциальности

Обновлено: 26 September 2026

**Conference Audio Recorder** by Siarhei Kuchuk

Название приложения: Conference Audio Recorder
Разработчик: Siarhei Kuchuk

Conference Audio Recorder записывает микрофон и динамики на этом компьютере и сохраняет файлы MP3 в выбранную вами папку. Учётная запись разработчика не создаётся. У разработчика нет сервера, который получает ваши записи, настройки или данные об использовании.

## Данные, которые разработчик не собирает

В приложении нет рекламы, аналитики, отчётов о сбоях и слежения. Разработчик не собирает, не продаёт и не передаёт персональные данные.

## Данные на вашем компьютере

### Записи

Звук записывается только в выбранную вами папку. По умолчанию это папка «Музыка» и вложенная папка на языке приложения. Эти файлы не отправляются разработчику.

### Настройки

Выбранная папка, устройства, тема и язык, в котором в последний раз открывали лицензию, политику и уведомления о сторонних компонентах, хранятся только на этом компьютере:

- Windows: `%LocalAppData%\ConferenceAudioRecorder\1.0\Settings`
- Linux: `~/.local/share/ConferenceAudioRecorder/1.0/Settings`
- macOS: `~/Library/Application Support/ConferenceAudioRecorder/1.0/Settings`

### Журналы

Диагностические журналы пишутся только на этом компьютере:

- Windows: `%LocalAppData%\ConferenceAudioRecorder\1.0\Logs`
- Linux: `~/.local/share/ConferenceAudioRecorder/1.0/Logs`
- macOS: `~/Library/Application Support/ConferenceAudioRecorder/1.0/Logs`

Эти файлы никуда не отправляются.

## Сеть

Приложение не отправляет записи и не связывается с разработчиком. Оно может открыть эти страницы в браузере. У этих сайтов свои политики конфиденциальности:

- [Страница проекта](https://github.com/drweb86/conference-audio-recorder)
- [Вопросы и ошибки](https://github.com/drweb86/conference-audio-recorder/issues)

Лицензия, эта политика и уведомления о сторонних компонентах показываются внутри приложения. Установки из Microsoft Store доставляет Microsoft. Само приложение не отправляет данные об использовании в Store.

## Дети

Приложение записывает звук на этом компьютере. Оно не предназначено для детей младше 13 лет.

## Третьи стороны

GitHub обрабатывает страницы, которые вы открываете. Microsoft Store обрабатывает установки и обновления из Store. Разработчик этот трафик не получает.

## Изменения

Обновления этой политики публикуются в этом файле в репозитории проекта.
