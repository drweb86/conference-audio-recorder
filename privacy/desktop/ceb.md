# Patakaran sa pagkapribado

Kataposang gi-update: 26 September 2026

**Conference Audio Recorder** by Siarhei Kuchuk

Ngalan sa app: Conference Audio Recorder
Tighimo: Siarhei Kuchuk

Ang Conference Audio Recorder nagrekord sa mikropono ug mga speaker niining kompyuter ug nagtipig og mga MP3 file sa folder nga imong gipili. Wala kini maghimo og account sa tighimo. Ang tighimo walay server nga modawat sa imong mga rekording, setting, o datos sa paggamit.

## Datos nga dili kolektahon sa tighimo

Walay ad, analytics, taho sa pagkahagsa, o pagsubay ang app. Ang tighimo dili mangolekta, magbaligya, o magpaambit og personal nga datos.

## Datos niining kompyuter

### Mga rekording

Ang narekord nga audio gisulat lang sa folder nga imong gipili. Sa default kana ang folder sa Musika, uban ang subfolder sa pinulongan sa app. Kadtong mga file dili ipadala sa tighimo.

### Mga setting

Ang gipili nga folder, mga device, tema, ug ang pinulongan nga kataposang gigamit alang sa lisensya, pagkapribado, ug mga pahibalo sa ikatulong partido gitipigan lang niining kompyuter:

- Windows: `%LocalAppData%\ConferenceAudioRecorder\1.0\Settings`
- Linux: `~/.local/share/ConferenceAudioRecorder/1.0/Settings`
- macOS: `~/Library/Application Support/ConferenceAudioRecorder/1.0/Settings`

### Mga log

Ang mga diagnostic log gisulat lang niining kompyuter:

- Windows: `%LocalAppData%\ConferenceAudioRecorder\1.0\Logs`
- Linux: `~/.local/share/ConferenceAudioRecorder/1.0/Logs`
- macOS: `~/Library/Application Support/ConferenceAudioRecorder/1.0/Logs`

Kadtong mga file dili ipadala bisan asa.

## Network

Ang app dili mag-upload og mga rekording ug dili mokontak sa tighimo. Mahimo niining ablihan kining mga panid sa browser. Kadtong mga site adunay ilang kaugalingong patakaran:

- [Panid sa proyekto](https://github.com/drweb86/conference-audio-recorder)
- [Mga pangutana ug sayop](https://github.com/drweb86/conference-audio-recorder/issues)

Ang lisensya, kini nga patakaran, ug ang mga pahibalo sa ikatulong partido gipakita sulod sa app. Ang mga install gikan sa Microsoft Store gihatag sa Microsoft. Ang app mismo dili magpadala og datos sa paggamit ngadto sa Store.

## Mga bata

Ang app nagrekord og audio niining kompyuter. Dili kini alang sa mga bata nga wala pay 13 anyos.

## Ikatulong partido

Ang GitHub nagproseso sa mga panid nga imong ablihan. Ang Microsoft Store nagproseso sa mga install ug update sa Store. Ang tighimo dili makadawat niana nga trapiko.
