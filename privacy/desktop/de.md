# Datenschutzrichtlinie

Zuletzt aktualisiert: 26 September 2026

**Conference Audio Recorder** by Siarhei Kuchuk

Name der Anwendung: Conference Audio Recorder
Name des Entwicklers: Siarhei Kuchuk

Conference Audio Recorder nimmt das Mikrofon und die Lautsprecher auf diesem Computer auf und speichert MP3-Dateien in einem Ordner, den Sie wählen. Es wird kein Entwicklerkonto angelegt. Der Entwickler betreibt kein Backend, das Ihre Aufnahmen, Einstellungen oder Nutzungsdaten empfängt.

## Daten, die der Entwickler nicht erhebt

Die App enthält keine Werbung, keine Analyse, keine Absturzberichte und kein Tracking. Der Entwickler erhebt, verkauft oder teilt keine personenbezogenen Daten.

## Daten auf Ihrem Computer

### Aufnahmen

Aufgenommener Ton wird nur in den von Ihnen gewählten Ordner geschrieben. Standardmäßig ist das Ihr Musikordner, in einem Unterordner in der Sprache der App. Diese Dateien werden nicht an den Entwickler gesendet.

### Einstellungen

Der gewählte Ordner, die Geräte, das Design und die zuletzt für Lizenz, Datenschutz und Drittanbieterhinweise verwendete Sprache werden nur auf diesem Computer gespeichert:

- Windows: `%LocalAppData%\ConferenceAudioRecorder\1.0\Settings`
- Linux: `~/.local/share/ConferenceAudioRecorder/1.0/Settings`
- macOS: `~/Library/Application Support/ConferenceAudioRecorder/1.0/Settings`

### Protokolle

Diagnoseprotokolle werden nur auf diesem Computer geschrieben:

- Windows: `%LocalAppData%\ConferenceAudioRecorder\1.0\Logs`
- Linux: `~/.local/share/ConferenceAudioRecorder/1.0/Logs`
- macOS: `~/Library/Application Support/ConferenceAudioRecorder/1.0/Logs`

Diese Dateien werden nirgendwohin gesendet.

## Netzwerk

Die App lädt keine Aufnahmen hoch und kontaktiert den Entwickler nicht. Sie kann diese Seiten im Browser öffnen. Diese Seiten haben eigene Datenschutzrichtlinien:

- [Projektseite](https://github.com/drweb86/conference-audio-recorder)
- [Fragen und Fehler](https://github.com/drweb86/conference-audio-recorder/issues)

Lizenz, diese Datenschutzrichtlinie und die Drittanbieterhinweise werden in der App angezeigt. Installationen aus dem Microsoft Store liefert Microsoft. Die App selbst sendet keine Nutzungsdaten an den Store.

## Kinder

Die App nimmt Ton auf diesem Computer auf. Sie richtet sich nicht an Kinder unter 13 Jahren.

## Dritte

GitHub verarbeitet die Seiten, die Sie öffnen. Der Microsoft Store verarbeitet Store-Installationen und Updates. Der Entwickler erhält diesen Datenverkehr nicht.

## Änderungen

Aktualisierungen dieser Richtlinie werden in dieser Datei im Projektarchiv veröffentlicht.
