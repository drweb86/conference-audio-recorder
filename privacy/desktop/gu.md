# ગોપનીયતા નીતિ

છેલ્લું અપડેટ: 26 September 2026

**Conference Audio Recorder** by Siarhei Kuchuk

ઍપનું નામ: Conference Audio Recorder
વિકાસકર્તા: Siarhei Kuchuk

Conference Audio Recorder આ કમ્પ્યુટર પર માઇક્રોફોન અને સ્પીકર રેકોર્ડ કરે છે અને MP3 ફાઇલો તમે પસંદ કરેલા ફોલ્ડરમાં સાચવે છે. તે વિકાસકર્તા ખાતું બનાવતું નથી. વિકાસકર્તા એવું સર્વર ચલાવતા નથી જે તમારી રેકોર્ડિંગ, સેટિંગ્સ અથવા વપરાશ ડેટા મેળવે.

## વિકાસકર્તા જે ડેટા એકત્ર કરતા નથી

ઍપમાં જાહેરાત, વિશ્લેષણ, ક્રેશ અહેવાલ અથવા ટ્રેકિંગ નથી. વિકાસકર્તા વ્યક્તિગત ડેટા એકત્ર, વેચતા કે શેર કરતા નથી.

## આ કમ્પ્યુટર પરનો ડેટા

### રેકોર્ડિંગ

રેકોર્ડ થયેલો ઑડિયો ફક્ત તમે પસંદ કરેલા ફોલ્ડરમાં લખાય છે. મૂળભૂત રીતે તે સંગીત ફોલ્ડર છે, ઍપની ભાષામાં પેટાફોલ્ડર સાથે. આ ફાઇલો વિકાસકર્તાને મોકલાતી નથી.

### સેટિંગ્સ

પસંદ કરેલું ફોલ્ડર, ઉપકરણો, થીમ અને લાઇસન્સ, ગોપનીયતા તથા તૃતીય-પક્ષ સૂચનાઓ માટે છેલ્લે વપરાયેલી ભાષા ફક્ત આ કમ્પ્યુટર પર રહે છે:

- Windows: `%LocalAppData%\ConferenceAudioRecorder\1.0\Settings`
- Linux: `~/.local/share/ConferenceAudioRecorder/1.0/Settings`
- macOS: `~/Library/Application Support/ConferenceAudioRecorder/1.0/Settings`

### લૉગ

નિદાન લૉગ ફક્ત આ કમ્પ્યુટર પર લખાય છે:

- Windows: `%LocalAppData%\ConferenceAudioRecorder\1.0\Logs`
- Linux: `~/.local/share/ConferenceAudioRecorder/1.0/Logs`
- macOS: `~/Library/Application Support/ConferenceAudioRecorder/1.0/Logs`

આ ફાઇલો ક્યાંય મોકલાતી નથી.

## નેટવર્ક

ઍપ રેકોર્ડિંગ અપલોડ કરતી નથી અને વિકાસકર્તાનો સંપર્ક કરતી નથી. તે બ્રાઉઝરમાં આ પાનાં ખોલી શકે છે. તે સાઇટ્સની પોતાની નીતિઓ છે:

- [પ્રોજેક્ટ પાનું](https://github.com/drweb86/conference-audio-recorder)
- [પ્રશ્નો અને ભૂલો](https://github.com/drweb86/conference-audio-recorder/issues)

લાઇસન્સ, આ નીતિ અને તૃતીય-પક્ષ સૂચનાઓ ઍપની અંદર દેખાય છે. Microsoft Storeમાંથી ઇન્સ્ટોલ Microsoft આપે છે. ઍપ પોતે વપરાશ ડેટા Storeને મોકલતી નથી.

## બાળકો

ઍપ આ કમ્પ્યુટર પર ઑડિયો રેકોર્ડ કરે છે. તે 13 વર્ષથી નાના બાળકો માટે નથી.

## તૃતીય પક્ષો

GitHub તમે ખોલેલા પાનાં પર પ્રક્રિયા કરે છે. Microsoft Store, Store ઇન્સ્ટોલ અને અપડેટ પર પ્રક્રિયા કરે છે. વિકાસકર્તા તે ટ્રાફિક મેળવતા નથી.
