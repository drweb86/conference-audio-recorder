# Patakaran sa privacy

Huling na-update: 26 September 2026

**Conference Audio Recorder** by Siarhei Kuchuk

Pangalan ng app: Conference Audio Recorder
Developer: Siarhei Kuchuk

Nire-record ng Conference Audio Recorder ang mikropono at mga speaker sa computer na ito at sine-save ang mga MP3 file sa folder na pipiliin mo. Hindi ito gumagawa ng developer account. Walang server ang developer na tumatanggap ng mga recording, setting, o datos ng paggamit.

## Datos na hindi kinokolekta ng developer

Walang ad, analytics, crash report, o tracking ang app. Hindi nangongolekta, nagbebenta, o nagbabahagi ng personal na datos ang developer.

## Datos sa computer na ito

### Mga recording

Ang na-record na audio ay isinusulat lang sa folder na pinili mo. Bilang default, ito ang folder na Musika, na may subfolder sa wika ng app. Hindi ipinapadala ang mga file sa developer.

### Mga setting

Ang napiling folder, mga device, tema, at ang wikang huling ginamit para sa lisensya, privacy, at mga abiso ng third party ay nasa computer na ito lang:

- Windows: `%LocalAppData%\ConferenceAudioRecorder\1.0\Settings`
- Linux: `~/.local/share/ConferenceAudioRecorder/1.0/Settings`
- macOS: `~/Library/Application Support/ConferenceAudioRecorder/1.0/Settings`

### Mga log

Ang mga diagnostic log ay isinusulat lang sa computer na ito:

- Windows: `%LocalAppData%\ConferenceAudioRecorder\1.0\Logs`
- Linux: `~/.local/share/ConferenceAudioRecorder/1.0/Logs`
- macOS: `~/Library/Application Support/ConferenceAudioRecorder/1.0/Logs`

Hindi ipinapadala ang mga file na iyon kahit saan.

## Network

Hindi nag-a-upload ng recording ang app at hindi kumokontak sa developer. Maaari nitong buksan ang mga pahinang ito sa browser. May sariling patakaran ang mga site na iyon:

- [Pahina ng proyekto](https://github.com/drweb86/conference-audio-recorder)
- [Mga tanong at bug](https://github.com/drweb86/conference-audio-recorder/issues)

Ang lisensya, ang patakarang ito, at ang mga abiso ng third party ay ipinapakita sa loob ng app. Ang mga install mula sa Microsoft Store ay ibinibigay ng Microsoft. Hindi nagpapadala ang app ng datos ng paggamit sa Store.

## Mga bata

Nagre-record ng audio ang app sa computer na ito. Hindi ito para sa mga batang wala pang 13.

## Mga third party

Pinoproseso ng GitHub ang mga pahinang binubuksan mo. Pinoproseso ng Microsoft Store ang mga install at update ng Store. Hindi natatanggap ng developer ang trapikong iyon.

## Mga pagbabago

Ipo-post ang mga update ng patakarang ito sa file na ito sa repository ng proyekto.
