# மூன்றாம் தரப்பு அறிவிப்புகள்

Conference Audio Recorder கீழுள்ள கூறுகளைப் பயன்படுத்துகிறது. அவை பயன்பாட்டின் சொந்த குறியீட்டின் CC0 அர்ப்பணிப்பில் இல்லை. ஒவ்வொன்றும் குறிப்பிட்ட உரிமத்தை வைத்திருக்கும்.

தொகுப்புப் பெயர்களும் உரிம உரையும் ஆங்கிலத்தில் உள்ளன, ஏனெனில் அவை சட்ட உரைகள்.

The Windows builds include the .NET runtime. It is listed with the MIT components.
